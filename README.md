# isitai.cbarange.com

Static demo of [isitai](https://github.com/cbarange/isitai): checks in the browser whether a text or a file carries proof or signals that it was made by AI. Files never leave the device.

This repository holds built files only. The source is in `site/` of the main repository; `pkg/` is produced by `site/build.sh` there.

Built from isitai commit `d39f4aa`.
